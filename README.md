# Movie Recommendation System 🎬

## Overview
This is a content-based movie recommendation system that suggests movies based on the similarity of their features including genres, keywords, taglines, cast, and director. The system uses natural language processing and machine learning techniques to provide personalized movie recommendations.

## Features
- 🔍 Intelligent movie search with fuzzy matching
- 📊 Similarity-based recommendations
- 💯 Percentage match scores for each recommendation
- 📱 Responsive web interface
- ⚡ Fast and efficient processing
- 🎯 Top 30 movie recommendations
